Java DSA practice repo — organized by problem patterns for interview prep.

> **Rule #1:** Learn the logic in Python first (fast to write, less boilerplate). Once a pattern clicks, redo 2-3 problems in Java. You're not learning DSA twice — you're learning it once and translating syntax.

> **Rule #2:** Every problem you solve, ask "what pattern is this?" before you code. That's the actual skill interviewers test.
